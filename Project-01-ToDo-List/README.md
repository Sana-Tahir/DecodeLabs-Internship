# Project 1 – To-Do List

## Overview

This project is part of my **DecodeLabs Internship**. It is a simple command-line To-Do List application developed in Python to practice fundamental programming concepts.

## Features

* Add new tasks
* View all tasks
* Menu-driven interface
* Exit the application

## Concepts Used

* Variables
* Lists
* User Input (`input()`)
* Conditional Statements (`if`, `elif`, `else`)
* `while` Loop
* `for` Loop
* `append()`
* `enumerate()`
