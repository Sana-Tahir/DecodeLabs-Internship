# Project 2 - Expense Tracker

## Description
A beginner-friendly Python Expense Tracker that allows users to enter multiple expenses and calculates the total amount spent.

## Features
- Accepts multiple expenses
- Calculates total spending
- Uses a running total (accumulator)
- Allows the user to type `done` to finish
- Handles invalid input

## Technologies
- Python

## How to Run
Run the `expense_tracker.py` file and enter your expenses.
Type `done` when finished.
